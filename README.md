# Chi-Cafe — homepage redesign concept

An unsolicited design concept for [chi-cafe.de](https://chi-cafe.de), by Kamran Alavi. **Not the official Chi-Cafe website.**

- **Homepage concept:** `index.html` (German, with an English toggle)
- **Design system:** `system.html`
- **Brand analysis & rationale:** [`BRAND-NOTES.md`](BRAND-NOTES.md)

## Idea

*Regt an, nicht auf.* The story follows Simon Sinek's Golden Circle — **Warum → Wie → Was** — in a calm, image-led layout inspired by the clarity of ouraring.com.

## Tech

Plain HTML, CSS and JavaScript — no build step, fast, and easy to move into WordPress, Shopify or any CMS. Fonts: Fraunces, Figtree, Noto Serif TC (Google Fonts). Responsive from 320px up, keyboard-accessible, and respects "reduce motion".

Run locally: `python -m http.server` in this folder, then open http://localhost:8000.
